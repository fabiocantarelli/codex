# Arquitetura Web

Estrutura sugerida:

```text
src/
├── app/
├── assets/
├── components/
│   ├── layout/
│   ├── shared/
│   └── ui/
├── features/
├── hooks/
├── lib/
├── services/
├── styles/
├── types/
└── utils/
```

Organize por feature quando a aplicação justificar.

Evite arquitetura excessiva.
