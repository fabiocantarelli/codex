# Política de Propriedade Intelectual e Segredo de Projeto

Todo projeto processado por uma skill deve ser tratado como patrimônio intelectual protegido de seu titular.

## Regras obrigatórias

- Não reutilizar código proprietário em outro projeto.
- Não transformar arquitetura interna em template público.
- Não copiar regras de negócio para exemplos genéricos.
- Não publicar documentação derivada sem autorização explícita.
- Não armazenar conteúdo do projeto em memória, banco vetorial ou dataset.
- Não compartilhar detalhes com agentes que não precisem deles.
- Não inferir autorização a partir da visibilidade pública do repositório.

## Segredo empresarial

Informações técnicas, comerciais, operacionais e estratégicas devem ser tratadas como segredo empresarial quando não houver autorização inequívoca para divulgação.

## Artefatos solicitados

A skill pode modificar ou gerar arquivos dentro do próprio projeto quando isso fizer parte da tarefa. Essa autorização não permite reutilização fora do escopo solicitado.
